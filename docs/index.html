An agent skill for your README

Your README can show your product working.

Ask your coding agent for a card. It reads your project and makes one animated SVG where your real interface runs. Not a GIF, and not a screen recording.

Make your card Star on GitHub

Every card here is live on Chan Meng's GitHub profile, made with the method and kit this skill ships. Each one is a single SVG file playing in your browser right now.

Why not a GIF

It looks like your product because it is built from it

What happens when you ask

You describe nothing. It reads your repo.

  1. Reads your product

    Colour tokens, fonts, the real logo file, brand rules and the copy you have already approved.

  2. Picks the story

    What does your product do that can be shown happening? That becomes the stage.

  3. Builds from the source

    Compiled, quoted or redrawn from the real thing. Nothing on the stage is imagined.

  4. Proves it plays

    A gate for GitHub's image sandbox, then every scene captured on light and dark.

Install

Make yours in one sentence

Free and open source under the MIT license. In Claude Code:

/plugin marketplace add ChanMeng666/chanmeng-svg-animation-studio
/plugin install chanmeng-svg-animation-studio@chanmeng-svg-animation-studio

Then ask for it in your project

Make an animated README card for this repo.

Another coding agent? Point it at SKILL.md. The kit is plain Node, and it is copied into your repo so the card rebuilds without the skill.
